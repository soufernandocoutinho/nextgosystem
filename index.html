É uma página de apresentação das soluções Next Go e de outros sistemas relacionados, organizada para ajudar você a identificar opções para diferentes necessidades do negócio. O catálogo é apresentado pelo Guia Panorama.

Os sistemas Next Go não possuem integração direta entre si. No entanto, alguns sistemas que utilizam recursos de cobrança contam com integração com a carteira Next Go Pay.
