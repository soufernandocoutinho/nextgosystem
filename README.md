# Next Go System

Página de apresentação dos sistemas do **Grupo Next Go**, desenvolvida em parceria de revenda com a **FC Soluções Digitais / Guia Panorama** e como **Franquia Licenciada Automatize**.

## Sobre o projeto

O catálogo apresenta soluções digitais para organizar a operação de negócios, melhorar o atendimento, divulgar produtos e serviços e conectar empresas aos seus clientes. A página reúne sistemas como atendimento via WhatsApp, agenda online, delivery, cardápio digital, cursos digitais, formulários, captação de leads, eventos e outras soluções do ecossistema Next Go.

Os sistemas não são comercializados diretamente nesta página. O catálogo funciona como uma vitrine informativa e encaminha o visitante para a página comercial ou o canal de apresentação de cada solução.

## Tecnologias utilizadas

- HTML5 semântico
- CSS3
- Bootstrap 5.3
- JavaScript
- Dados estruturados Schema.org
- Meta tags para SEO e redes sociais

## Estrutura

```text
index.html              Página principal e conteúdo do catálogo
assets/css/             Estilos da interface e do banner de consentimento
assets/js/              Interações da página e gerenciamento de consentimento
assets/img/             Identidade visual e imagens dos sistemas
```
